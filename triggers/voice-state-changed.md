# Voice State Changed

**Description:** Triggers when a user's voice state changes, such as joining, leaving, or moving between voice channels.

**Inputs:**

* Store old state in variable
* Store new state in variable

**Variable Types:**&#x20;

* Voice State

**Behaviour:** Stores the previous voice state in the variable assigned to "old" and the new voice state in the variable assigned to "new", then continues with the next actions.

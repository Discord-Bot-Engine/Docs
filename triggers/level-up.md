# Level Up

**Description:** Trigger when a user levels up.

**Inputs:**

* Store level in variable
* Store message in variable
* Store user in variable
* Store member in variable
* Store channel in variable
* Store server in variable

**Variable Types:**&#x20;

* Number
* Message
* User
* Member
* Channel
* Server

**Behaviour:** Stores the new level, the message that triggered the level up, the user, member, channel, and server related to the level up event. Then continues with the next actions.

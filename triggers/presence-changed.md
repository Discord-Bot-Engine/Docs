# Presence Changed

**Description:** Triggers when a user's presence updates, such as status changes (online, offline, idle) or activity changes.

**Inputs:**

* Store old presence in variable
* Store new presence in variable

**Variable Types:**&#x20;

* Presence

**Behaviour:** Stores the previous presence in the variable assigned to "old" and the updated presence in the variable assigned to "new", then continues with the next actions.

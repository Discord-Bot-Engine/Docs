# Message Sent

**Description:** Trigger when a new message is sent (not by the bot itself).

**Inputs:**

* Store message in variable
* Store user in variable
* Store member in variable
* Store channel in variable
* Store server in variable

**Variable Types:**&#x20;

* Message
* Member
* User
* Channel
* Server

**Behaviour:** Stores the message, author user, member, channel, and server related to the sent message. Then continues with the next actions.

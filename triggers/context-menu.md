# Context Menu

**Description:** Trigger when a context menu (user or message) with the name matching the trigger.

**Inputs:**

* Menu Type (User or Message)
* Store target message in variable (shown if Menu Type is Message)
* Store target user in variable (shown if Menu Type is User)
* Store target member in variable (shown if Menu Type is User)
* Store interaction in variable
* Store user in variable
* Store member in variable
* Store channel in variable
* Store server in variable

**Variable Types:**&#x20;

* Context Menu Interaction
* User
* Member
* Server
* Channel
* Message

**Behaviour:** Stores relevant context menu interaction details such as interaction, target user, target member, target message, channel, and server in specified variables. Then continues with the next actions.

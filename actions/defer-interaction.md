# Defer Interaction

**Description:** Defers a response to an interaction (slash command, button, etc).

**Inputs:**

* Interaction
* Is ephemeral? (True/False)

**Outputs:**

* action

**Variable Types:**

* Command Interaction
* Context Menu Interaction
* Button Interaction
* Select Menu Interaction

**Behaviour:** Defers the interaction reply optionally as ephemeral. Continues to next action.

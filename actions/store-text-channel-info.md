# Store Text Channel Info

**Description:** Stores information about a text channel.

**Inputs:**

* Channel
* Info (Id, Name, Topic, NSFW, Slowmode, Permissions, Messages, etc.)
* Store value in variable

**Outputs:**

* action

**Variable Types:**

* Channel
* Server
* Text
* Boolean
* Number
* Date
* List

**Behaviour:** Fetches the chosen property from the text channel and stores it.

# Store Random Number

**Description:**\
Generates a random number between the specified minimum and maximum values and stores it in a variable.

**Inputs:**

* Min
* Max
* Store number in variable

**Outputs:**

* action

**Variable Types:**

* Number

**Behaviour:**\
Calculates a random integer in the inclusive range from Min to Max, stores it in the selected variable, and then continues to the next action.

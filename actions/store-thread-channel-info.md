# Store Thread Channel Info

**Description:** Stores information about a thread channel.

**Inputs:**

* Channel
* Info (Id, Name, Topic, Archived, Locked, Members, Messages, etc.)
* Store value in variable

**Outputs:**

* action

**Variable Types:**

* Channel
* Server
* Text
* Boolean
* Number
* Date
* List

**Behaviour:** Retrieves specified thread property and stores it.

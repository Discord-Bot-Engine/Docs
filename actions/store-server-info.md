# Store Server Info

**Description:** Stores information about a server (guild).

**Inputs:**

* Server
* Info (Banner URL, Channels, Members, Roles, Owner, Verification Level, etc.)
* Store value in variable

**Outputs:**

* action

**Variable Types:**

* Server
* Channel
* Member
* Number
* List
* Boolean
* Date
* Text

**Behaviour:** Fetches the selected piece of server info and stores it. Includes image options for URL fields.

# Store Category Channel Info

**Description:** Stores various properties of a category channel.

**Inputs:**

* Channel
* Info (Name, Position, Is Deletable, Is Manageable, Is Viewable, Server, Channels)
* Store value in variable

**Outputs:**

* action

**Variable Types:**

* Channel
* Server
* Text
* Boolean
* Number
* List

**Behaviour:** Based on selected info, retrieves the corresponding property of the category channel and stores it.

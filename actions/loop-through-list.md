# Loop Through List

**Description:** Loops through every element in a list and executes loop actions.

**Inputs:**

* List
* Store element in variable
* Store element position in variable

**Outputs:**

* action
* loop

**Variable Types:**

* List

**Behaviour:** Iterates through list elements, storing each element and its position in variables, triggers the "loop" output for each element, and "action" when done.

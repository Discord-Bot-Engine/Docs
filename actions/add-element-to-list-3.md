# Add Text To Image Builder

**Description:**\
Adds text inside an image builder.

**Inputs:**

* Image builder or container
* Text
* X offset
* Y offset
* Font family
* Font size
* Font color&#x20;
* Animation

**Outputs:**

* action

**Variable Types:**

* Image Builder
* Container

**Behaviour:**

Adds text to the selected image builder or container, then proceeds with the next actions.

# Sort List

**Description:** Sorts a list using a custom sorting action between elements.

**Inputs:**

* List
* Store element A in variable
* Store element B in variable
* Store sorted list in variable

**Outputs:**

* action
* sort

**Variable Types:**

* List

**Behaviour:** Implements quicksort partitioning with custom comparison using the "sort" output. Based on comparison result, reorders elements. After sorting completes, stores sorted list and continues.

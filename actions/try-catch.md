# Try Catch

**Description:** Wraps the following actions in a try catch block. If an error happens, it is captured and execution switches to the error output.

**Inputs:**

* Store error in variable

**Outputs:**

* action
* on error

**Variable Types:**&#x20;

* Text

**Behaviour:** Runs the action output normally. If any error occurs during execution, the error is stored in the selected text variable and the flow continues through the on error output instead.

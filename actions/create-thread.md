# Create Thread

**Description:** Creates a thread channel under a parent channel.

**Inputs:**

* Parent channel
* Thread name
* Thread type (Public, Private, Announcement)
* Auto-archive duration (One Day, One Hour, One Week, Three Days)
* Store thread in variable

**Outputs:**

* action

**Variable Types:**

* Channel

**Behaviour:** Creates a new thread with specified name, type, auto-archive duration under the parent channel. Stores the thread channel variable.

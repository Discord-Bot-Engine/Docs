# Store Voice Channel Info

**Description:** Stores various information about a voice channel.

**Inputs:**

* Channel
* Info (Id, Name, Bitrate, User Limit, Members, Messages, etc.)
* Store value in variable

**Outputs:**

* action

**Variable Types:**

* Channel
* Server
* Text
* Boolean
* Number
* List

**Behaviour:** Retrieves requested property from the voice channel and stores it.

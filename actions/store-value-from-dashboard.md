# Store Value From Dashboard

**Description:** Stores a value from dashboard input for a server.

**Inputs:**

* Server
* Input (dashboard input name)
* Store value in variable

**Outputs:**

* action

**Variable Types:**

* Server
* Text
* Role
* Channel
* Member
* Mentionable

**Behaviour:** Gets the dashboard input value by name and converts to appropriate object type, then stores.

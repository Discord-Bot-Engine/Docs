# Store User As Member

**Description:** Fetches and stores a member object from a user in a server.

**Inputs:**

* Server
* User
* Store member in variable

**Outputs:**

* action

**Variable Types:**

* Member
* User
* Server

**Behaviour:** Retrieves the specified server and user variables, fetches the corresponding member from the server using the user id, stores it in the selected member variable, then continues to the next action.

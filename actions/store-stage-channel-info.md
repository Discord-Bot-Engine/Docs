# Store Stage Channel Info

**Description:** Stores information from a stage voice channel.

**Inputs:**

* Channel
* Info (Id, Name, Bitrate, User Limit, Members, Messages, etc.)
* Store value in variable

**Outputs:**

* action

**Variable Types:**

* Channel
* Server
* Text
* Boolean
* Number
* List

**Behaviour:** Retrieves the specified property from the stage channel and stores in the variable.

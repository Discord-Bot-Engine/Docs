# Store Response From HTTP Request

**Description:** Sends an HTTP request and stores the response.

**Inputs:**

* URL
* Request type (GET, POST)
* Response type (Text, JSON, XML)
* Store response in variable
* Body (for POST)
* Headers (list)

**Outputs:**

* action

**Variable Types:**

* Text
* JSON

**Behaviour:** Executes the HTTP request with optional headers and body, stores the response in chosen format.

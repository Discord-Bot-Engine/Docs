# Filter List

**Description:** Filters elements in a list based on custom logic.

**Inputs:**

* List
* Store element in variable
* Store element position in variable
* Store list in variable (filtered list)

**Outputs:**

* action
* filter

**Variable Types:**

* List

**Behaviour:** Iterates through the list elements. For each, executes filter actions. You can continue, return (include element) or break. Stores the filtered list after completion.

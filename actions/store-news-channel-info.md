# Store News Channel Info

**Description:** Stores various information from a news channel.

**Inputs:**

* Channel
* Info (Id, Name, Topic, Is NSFW, Created At, Slowmode, etc.)
* Store value in variable

**Outputs:**

* action

**Variable Types:**

* Channel
* Server
* Text
* Boolean
* Number
* Date
* List

**Behaviour:** Extracts the selected property from the news channel and stores it in variable.

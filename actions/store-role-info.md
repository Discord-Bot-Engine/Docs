# Store Role Info

**Description:** Stores information about a role.

**Inputs:**

* Role
* Info (Color, Created At, Icon URL, Id, Members, Permissions, etc.)
* Store value in variable

**Outputs:**

* action

**Variable Types:**

* Role
* Number
* Boolean
* List
* Date
* Text
* Member
* Server
* Channel

**Behaviour:** Gets the property specified from the role and stores it. Image options available for icon URLs.

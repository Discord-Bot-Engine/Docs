# Store XP Card As WebP

**Description:** Generates an XP card image for a member and stores as a WebP buffer.

**Inputs:**

* Member
* XP Member Data Field
* Max XP Member Data Field
* Level Member Data Field
* Store webp buffer in variable

**Outputs:**

* action

**Variable Types:**

* Buffer
* Member

**Behaviour:** Fetches XP, max XP, and level values for a member, renders an HTML XP card, records as WebP animation, and stores the buffer.

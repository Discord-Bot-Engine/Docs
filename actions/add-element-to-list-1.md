# Add Image To Image Builder

**Description:**\
Creates an image inside an image builder.

**Inputs:**

* Image builder
* Image URL
* X offset
* Y offset
* Width
* Height
* Roundness&#x20;
* Animation

**Outputs:**

* action

**Variable Types:**

* Image Builder

**Behaviour:**

Adds an image to the selected image builder, then proceeds with the next actions.

# Store Member Info

**Description:** Stores various information of a guild member.

**Inputs:**

* Member
* Info (Avatar URL, Display Name, Joined At, Roles, Permissions, etc.)
* Store value in variable

**Outputs:**

* action

**Variable Types:**

* Member
* User
* Server
* Text
* Number
* Boolean
* Date
* List
* Channel
* Voice State
* Presence

**Behaviour:** Gets the specified information property from the member and stores it, including image options for URL fields.

# Add Image To Image Builder

**Description:**\
Creates an image inside an image builder.

**Inputs:**

* Image builder or container
* Image URL
* X offset
* Y offset
* Width
* Height
* Roundness&#x20;
* Animation

**Outputs:**

* action

**Variable Types:**

* Image Builder
* Container

**Behaviour:**

Adds an image to the selected image builder or container, then proceeds with the next actions.

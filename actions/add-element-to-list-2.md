# Add Text To Image Builder

**Description:**\
Adds text inside an image builder.

**Inputs:**

* Image builder
* Text
* X offset
* Y offset
* Align to
* Font family
* Font size
* Font color&#x20;
* Animation

**Outputs:**

* action

**Variable Types:**

* Image Builder

**Behaviour:**

Adds text to the selected image builder, then proceeds with the next actions.

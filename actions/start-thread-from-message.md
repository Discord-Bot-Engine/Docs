# Start Thread From Message

**Description:** Starts a new thread from a message.

**Inputs:**

* Parent message
* Thread name
* Auto-archive duration (One Day, One Hour, One Week, Three Days)
* Store thread in variable

**Outputs:**

* action

**Variable Types:**

* Channel
* Message

**Behaviour:** Creates a thread from the given message with specified name and auto-archive duration, stores the new thread channel.

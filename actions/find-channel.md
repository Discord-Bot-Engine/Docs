# Find Channel

**Description:** Finds a channel in a server by Id or Name and type.

**Inputs:**

* Server
* By (Id or Name)
* Type (Text, Voice, Announcement, Stage, Forum, Category, Thread) \[only shown if By is Name]
* Value (name or id)
* Store channel in variable

**Outputs:**

* action

**Variable Types:**

* Channel
* Server

**Behaviour:** Fetches or searches channel by id or name and stores the result. Continues execution.

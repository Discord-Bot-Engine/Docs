# Play Song From Folder

**Description:** Plays a song from a local folder in a voice channel.

**Inputs:**

* Voice channel
* Folder to search song
* File Extensions (list)
* Song (name to search)
* Clear queue? (True/False)

**Outputs:**

* action

**Variable Types:**

* Channel

**Behaviour:** Searches specified folder for a song matching name and extensions, optionally clears the queue, then plays the song in the voice channel.

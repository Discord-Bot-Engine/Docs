# Check Mentionable Type

**Description:** Checks if a mentionable is of a specific type: User, Role, or Member.

**Inputs:**

* Mentionable
* Type (User, Role, Member)

**Outputs:**

* true
* false

**Variable Types:**

* User
* Role
* Member

**Behaviour:** Tests the type of the mentionable variable and continues through "true" if it matches, otherwise "false".

# Store User Info

**Description:** Stores information about a user.

**Inputs:**

* User
* Info (Username, Discriminator, Avatar URL, Banner URL, Created At, Is Bot, DM Channel, etc.)
* Store value in variable

**Outputs:**

* action

**Variable Types:**

* User
* Text
* Boolean
* Date
* Number
* Channel

**Behaviour:** Fetches the requested user property and stores. Image URL options available.

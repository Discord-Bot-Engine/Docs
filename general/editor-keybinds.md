# Editor Keybinds

* CTRL + C: Copy
* CTRL + V: Paste
* CTRL + D: Duplicate
* CTRL + Z: Undo
* CTRL + Y: Redo
* CTRL + S: Save
* CTRL + A: Select All
* CTRL + CLICK: Select Multiple
* SHIFT + DRAG: Drag Select
* BACKSPACE: Delete
* RIGHT CLICK: Insert Node At Position
* RIGHT CLICK: Insert Variable In Field (${variables\["variable"]})

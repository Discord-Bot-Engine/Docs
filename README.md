# Bot Creation

1. Go to [https://discord.com/developers/applications](https://discord.com/developers/applications)
2. Click New Application and enter your bot's name
3. Select your new bot in the My Applications section
4. In the sidebar, click on the Bot tab
5. Click on the Reset Token button and copy the new token
6. Enable Presence Intent, Server Members and Message Content Intents
7. In the sidebar, click on the OAuth2 tab
8. Click on the Reset Secret button and copy the new client secret
9. Click on Add Redirect and type [http://localhost:3000/auth/callback](http://localhost:3000/auth/callback) then click Save Changes
10. In Discord Bot Engine, click on the plus icon in the top right
11. Enter your bot name and select the project's folder then click Create
12. Go to the Settings page
13. Enter your bot token and client secret then click on the save icon
14. Click on the link icon to invite your discord bot
